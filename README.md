# SIMFOUND — сборка APK
1. Создай репозиторий на GitHub и загрузи в него все файлы этой папки (включая .github).
2. Открой вкладку Actions → Build APK → дождись зелёной галочки.
3. Внутри запуска скачай артефакт SIMFOUND-apk (там app-debug.apk) и установи на телефон.
Либо открой папку в Android Studio и нажми Build → Build APK.

Список номеров: в приложении кнопка «Список номеров» (или файл app/src/main/assets/numbers.txt).
Координаты и цвета окон игры: app/.../Layout.kt
